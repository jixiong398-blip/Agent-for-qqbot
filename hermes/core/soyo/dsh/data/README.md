# Soyo 原生数据、行动脑与便签界面

这是 DSH 官方 Web 的支持面板，不另建聊天或发送入口。

- 左侧底部 **行动脑会话**：从真实 task ledger 获取子会话地址，打开官方原生历史；不会重跑行动。
- 右侧 **双脑区**：默认列出全部父会话的行动任务，可切换当前会话；显示工具证据和报告交回状态。
- 右侧 **跨会话便签**：选择家里/QQ 场景，查看来源、内容、next_time/wake、已读与回信。
- 右侧 **记忆与数据**：保留既有原话、记忆、事件和平台回执。

官方普通侧栏会隐藏 origin=subagent。独立入口保留真实父子地址，不能通过改写原日志或把子会话冒充 owner 解决可见性。
便签不是 QQ publication；读取状态来自完成回合，QQ 投递事实仍看独立平台 receipt。
