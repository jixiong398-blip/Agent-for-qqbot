测试仅使用源码之外的新私有实例、新端口和合成会话，不改用户原有 DSH profile、凭据、默认模型或 QQ 登录状态。
模型验收只证明实际短回合与工具协作，不等于 256K 满上下文容量/并发压测或模型输出质量认证。
WSL 使用仅测试用的回环—本机标准输入输出桥访问 Windows 的模型回环，不开放 LAN listener、不改系统网络设置。
维护者的既有跨机演示属于独立私有维护环境，不是用户产品配置，不随包分发。
本机直接入口意味着同机访问者具有实例管理能力；不提供普通 LAN / 公网 / `0.0.0.0` 监听。
运行时回滚的文件事务测试不等于数据库格式降级、断电恢复或完整生产回滚已经验收。

## 复现离线契约测试

在独立开发环境安装 Python 测试依赖：`python -m pip install -e "hermes/core[test]"`。
运行 `python -m pytest hermes/core/tests/soyo -q`。Linux 使用 `python3`；临时目录须位于支持私有 POSIX 权限的文件系统。
JS 使用 Node 内置测试器运行 `hermes/core/tests/soyo/*.test.mjs` 与 `dsh_*_test.mjs`。
这些契约测试不需要云端 Key、模型调用或真实 QQ。

真实 UI / 模型验收必须另外明确选择私有实例、供应商与模型；不能自动读取另一套部署的凭据。
