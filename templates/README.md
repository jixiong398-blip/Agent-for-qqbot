# Bot 1.0 公开模板

**Bot 是中性产品称呼，不是固定人设。** 角色名、人物设定、语言和别名都由使用者自取；不提供作者的私人角色、账号、模型或连接信息。

| 文件 | 用途 |
|---|---|
| `deployment.example.json` | 云端 / 自定义 OpenAI 兼容供应商字段示意；显式 `auth_mode=bearer` |
| `deployment.local.example.json` | 运行在服务机回环地址上的本地模型；显式 `auth_mode=none`、无真实 Key |
| `SOUL-template.md` | 自选名字与人格；填好后在向导中导入 / 保存为预设 |
| `BEHAVIOR-template.md` | 可选行为补充，保存到私有 `persona/BEHAVIOR.md` |
| `.env.template` | 启动器环境变量说明，不自动加载，不存凭据 |
| `config-template.yaml` | 旧版兼容指引，已退休，不会加载为配置 |

## 使用顺序

1. 先安装，用向导生成完整的私有 `deployment.json`；JSON 示例只是字段说明，不要整份覆盖。
2. 云端填供应商地址 / 模型 / Key；本地填服务机回环地址 / 模型并选择“本地免 Key”。
   上下文与输出预算占位符须换成供应商实际支持的整数；图片能力和思考档位按其文档明确配置。
3. 默认两个脑复用模型，仍是独立职责与会话；取消复用后分别填写。可保存命名供应商方案。
4. 填角色名，编辑 / 导入人格并保存。软件不会执行 `{{占位符}}`，也不会自动将人格标题同步为角色名。
5. 保持 `onebot.enabled=false` 先体验 Web；QQ 账号和 Token 在显式接入时再填，不能放进公开模板。

## 本机访问边界

预构建用户直接在原生 DSH 的 Bot 配置窗口填写模型和人格，不需要手改这些文件。
产品只绑定 `127.0.0.1`，直接进入，无额外 Bot Key 页；不提供公网 / LAN / 远程组网配置。
维护者使用的远程工具不属于产品安装流程。这不取消模型 API Key、OneBot Token 或内部服务凭据。

`hermes/templates/` 只保留旧路径指引，不再另存一份有效的人设 / 供应商配置。修改以本目录为准。

端口默认值、产品 URL 和固定依赖来源集中在 `application.toml`；实例值可在向导或私有
JSON 中覆盖。安全限制、协议字段、版本/SHA pin 与加密格式常量不是用户部署绑定。
